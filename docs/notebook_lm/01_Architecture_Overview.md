# معمارية نظام Septimus OS (Architecture Overview)

## نظرة عامة (High-Level Overview)

نظام **Septimus OS** هو منصة تشغيلية (Enterprise Orchestration) مصممة لتلبية متطلبات المؤسسات الحديثة من حيث الاستقلالية، الأمان، وتكامل الذكاء الاصطناعي.
يعتمد النظام معمارية متطورة تفصل بين مهام المعالجة الإجرائية ومهام الذكاء الاصطناعي، لضمان استقرار عالي وتوسع غير متماثل (Asymmetric Scaling).

## التقسيم الهيكلي (Core Components)

ينقسم النظام إلى ثلاثة أجزاء رئيسية:

1. **الواجهة الأمامية (Frontend - Next.js 15):**
   - **التقنية:** مبنية باستخدام Next.js (App Router) و React 19.
   - **الواجهة:** تصميم مرن وواجهات مدعومة بـ Tailwind CSS مع دعم اللغتين (العربية والإنجليزية).
   - **الهدف:** توفير واجهة مستخدم سريعة، مستقرة، وتدعم الـ (Widgets) في اللوحة الرئيسية.

2. **المحرك الأساسي (Backend Core - Golang):**
   - **التقنية:** مكتوب بلغة Go باستخدام إطار العمل Fiber.
   - **الهدف:** معالجة البيانات الإجرائية (العمليات اليومية)، نظام الصلاحيات (RBAC)، المحادثات (Chat & Channels)، المراسلات الرسمية (Diwan)، وإدارة المساحات التخزينية.
   - **قاعدة البيانات:** يعتمد على GORM للاتصال بـ PostgreSQL.
   - **نمط البيانات المرن:** يعتمد بشكل كبير على نمط (JSONB Entity Pattern) لتخزين البيانات المعقدة والمرنة مثل إعدادات المؤسسة، رسائل الـ JSON، والمرفقات دون تعقيد المخططات (Schema).

3. **المحرك الذكي السيادي (AI Sidecar - Python FastAPI):**
   - **التقنية:** مبني باستخدام Python و FastAPI.
   - **الهدف:** معالجة جميع مهام الذكاء الاصطناعي بشكل معزول (التدقيق القانوني، التلخيص، المحللين الذكيين Agents، استرجاع المعلومات RAG).
   - **الميزة:** هذا الفصل يمنع أعباء الـ (AI) من التأثير على سرعة النظام الأساسي (Golang).

## قنوات الاتصال والـ WebSockets

- يستخدم النظام تقنية الـ **WebSockets** للاتصال المباشر (Real-time).
- المحادثات (الرسائل، التحديثات المباشرة، إشعارات الوكلاء) تمر عبر نظام WebSocket المدمج في (Golang Backend).

## التوسع والفصل (Separation of Concerns)

- **Golang:** يعالج آلاف الطلبات المتزامنة (Concurrency) في الثانية، وهو مثالي لإدارة المستخدمين، البيانات الأساسية، والـ WebSockets.
- **Python:** يتحمل معالجة النماذج اللغوية (LLMs)، وتحليل المستندات، والتي تتطلب وقت معالجة أطول ولا يجب أن توقف المحرك الأساسي.
