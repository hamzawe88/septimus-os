# تحليل قاعدة بيانات Septimus OS (Database Schema)

## الفلسفة الأساسية (JSONB Entity Pattern)
يعتمد Septimus OS على نمط متقدم في تصميم قواعد البيانات وهو **JSONB Entity Pattern** في قاعدة بيانات PostgreSQL.
بدلاً من إنشاء عشرات الجداول المعقدة والروابط (Relations) التي تبطئ الاستعلامات وتصعّب التوسعة، نستخدم الجداول للأعمدة الأساسية القابلة للبحث (Searchable Indices) بينما نخزن باقي البيانات المرنة والمخصصة داخل عمود `Data` (من نوع JSONB).

## الجداول الأساسية (Core Tables)

### 1. جدول مساحات العمل (Workspaces)
- **ID:** `uuid` (المفتاح الأساسي).
- **Name:** اسم مساحة العمل.
- **MaxUsers:** الحد الأقصى للمستخدمين (لأغراض الـ SaaS).
- **StorageQuotaBytes:** الحصة التخزينية المسموحة لمساحة العمل.
- **StorageUsedBytes:** المساحة التخزينية المستهلكة حالياً.
- **Data:** إعدادات الـ SaaS مثل:
  - `billing_plan`: نوع الاشتراك.
  - `ai_enabled`: هل ميزات الذكاء الاصطناعي مفعلة.

### 2. جدول الأقسام (Departments)
- **ID:** `uuid`.
- **Name:** اسم القسم (مثل: الشؤون القانونية).
- **WorkspaceID:** ربط القسم بمساحة العمل.
- **ParentID:** لدعم الهيكلية الشجرية (Sub-departments).
- **ManagerID:** مدير القسم.
- **StorageQuotaBytes:** الحصة المخصصة للقسم.
- **MaxFileSize:** أقصى حجم للملف الواحد المرفوع داخل القسم.

### 3. جدول المستخدمين (Users)
- **ID:** `uuid`.
- **Email:** البريد الإلكتروني.
- **PasswordHash:** كلمة المرور المشفرة.
- **WorkspaceID:** المساحة التي يتبع لها.
- **Data:** تفاصيل الحساب، الحالة (online/offline/busy)، ونوع العضوية.

### 4. القنوات والمحادثات (Channels)
- **ID:** `uuid`.
- **WorkspaceID:** ربط القناة بمساحة العمل.
- **IsSystem:** هل القناة أساسية ولا يمكن حذفها (مثل: القناة العامة).
- **Data:** نوع القناة (عامة / خاصة / DM)، أسماء الأعضاء (للبحث السريع)، وصورة القناة.

### 5. جدول إدارة الملفات والمرفقات (FileRecords)
- **ID:** `uuid`.
- **WorkspaceID:** مساحة العمل.
- **DepartmentID:** القسم المالك للملف.
- **UploaderID:** المستخدم الذي رفع الملف.
- **OriginalName:** اسم الملف الأصلي.
- **Size:** حجم الملف بالبايتات (Bytes).
- **Path:** المسار في نظام الملفات.

## فوائد هذا المخطط
1. **Multi-Tenancy:** كل البيانات مربوطة بـ `WorkspaceID` مما يضمن العزل التام للمؤسسات.
2. **المرونة:** عمود الـ `Data` (JSONB) يسمح لنا بإضافة ميزات جديدة (مثل إعدادات متقدمة لكل مستخدم أو قسم) بدون أي تعقيد أو احتياج لعمل `Migration` لقاعدة البيانات.
