# الأمان والتدقيق (Security & Audit)

## 1. المصادقة والترخيص (Authentication & Authorization)
- **JWT (JSON Web Tokens)**: يعتمد النظام على توكنز مشفرة بـ HMAC للتحقق من هوية المستخدم. يتم إرسال التوكن إما في الـ `Authorization` Header كـ `Bearer`، أو يتم قراءته من الـ Cookies عبر واجهة الويب.
- **RBAC (Role-Based Access Control)**: نظام إدارة صلاحيات متطور يعتمد على الأدوار (Roles). كل مستخدم له دور (مثل: Owner, Admin, User, Guest) يحدد بدقة ما يمكنه رؤيته وتعديله.
- يتم تطبيق التحقق من الصلاحيات كـ `Middleware` في مستوى لغة Go (`RequireInternalToken`, `JWTMiddleware`, `CheckPermission`) لضمان عدم تجاوز الحماية حتى لو أخطأت واجهة المستخدم.

## 2. مركز التدقيق الموحد (Unified Audit Center)
لضمان أقصى درجات الشفافية والتتبع، يسجل النظام كل نشاط يقوم به أي مستخدم.
- **تسجيل الأنشطة**: يتم حفظ أي عملية إنشاء، تعديل، حذف، أو دخول في جدول السجلات (Audit Logs).
- **التصنيف الذكي (Smart Filtering)**:
  - `Security Events`: الأحداث الأمنية الخطيرة مثل (`auth.login`, `auth.failed`, `settings.update`).
  - `User Activity`: الأنشطة العامة مثل كتابة رسالة أو إرسال ملف (`entity.create`, `channel.delete`).
- **المراقبة الحية (Live Monitoring)**: تظهر الأحداث الأمنية في "ودجت المراقبة" في لوحة القيادة فور حدوثها لتنبيه المدير لأي اختراق محتمل.

## 3. التشفير وحماية البيانات (Data Encryption)
- **Crypto Services**: تمتلك لغة Go مكتبة تشفير داخلية تقوم بتشفير أي بيانات حساسة (مثل مفاتيح الـ API للخدمات الخارجية، كلمات المرور، ورموز الدفع) قبل حفظها في قاعدة البيانات باستخدام خوارزميات التشفير المتماثل القوية (AES-GCM).
- **Masking**: عند استرجاع بعض البيانات الحساسة للعرض (مثل آخر أرقام بطاقة الدفع)، يتم إخفاؤها (Masking) باستثناء آخر 4 أرقام لتجنب التسريب إذا تم اختراق واجهة العرض.

## 4. بوابات الميزات (Feature Gates)
- للحماية من وصول المستخدمين في الخطط المجانية למيزات مدفوعة (مثل الذكاء الاصطناعي، التكامل مع تطبيقات الطرف الثالث)، يوجد `FeatureGateMiddleware`.
- يتحقق الـ Middleware من الخطة الحالية للمساحة (Workspace Plan) قبل السماح بمرور طلب الـ API، وفي حال عدم وجود الصلاحية المادية، يتم رفض الطلب فوراً من الخادم مع إرجاع `403 Forbidden` مخصص يطلب من المستخدم ترقية الباقة.
